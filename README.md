# Web App — Project Management & ERP System

> **PRB IT Global Sdn Bhd** | Custom Software for SME Engineering & Construction Clients (Malaysia)

## Overview

A full-featured, cloud-based **Project Management and Enterprise Resource Planning (ERP)** system purpose-built for small and medium-sized engineering and construction firms in Malaysia. This platform consolidates project planning, resource allocation, procurement, finance, and reporting into a single unified interface.

## Key Features

| Module | Description |
|---|---|
| Project Planning | Gantt charts, milestone tracking, WBS management |
| Resource Management | Labour, equipment, and material allocation |
| Procurement & Purchasing | PO generation, vendor management, approval workflows |
| Financial Management | Budgeting, cost tracking, invoicing, and P&L reports |
| Document Control | Centralised document repository with version control |
| Compliance Tracking | CIDB, DOSH, and local regulatory compliance checklists |
| Reporting & Analytics | Real-time dashboards and exportable reports |

## Technology Stack

- **Frontend:** React.js, TypeScript, TailwindCSS
- **Backend:** Node.js / Express or Django REST Framework
- **Database:** PostgreSQL
- **Auth:** OAuth2 / JWT
- **Hosting:** AWS / Azure (Malaysia region)

## Target Users

Engineering consultants, construction contractors, quantity surveyors, and project managers operating within Malaysian SME construction firms.

## Getting Started

```bash
git clone https://github.com/PRB-IT-Global-Sdn-Bhd/web-pm-erp-system.git
cd web-pm-erp-system
npm install
npm run dev
```
